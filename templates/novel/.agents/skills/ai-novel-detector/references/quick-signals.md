# 通常診断：クラスタ走査と文体シグナル

毎話の検証と単発診断で、Full Detectへ進むべき箇所を短時間で見つける。
ここにある項目も著者性の証明には使わない。

## 1. 最初にスクリプト結果を引用する

品質事故（マークダウン残り・AI返答混入・文字種混入・記号揺れ・空行異常）は決定論スクリプトの管轄。本Skillで再走査せず、結果を証拠として引用する。

```bash
bash scripts/check.sh --strict <対象ファイル>
python3 scripts/normalize_blanklines.py --check <対象ファイル>
python3 scripts/cliche_check.py <対象ファイル>
```

`check.sh` の[NG]が一件でもあれば、その局所の改稿優先度を最高にする。正典矛盾・視点違反・情報格差の破れに気づいた場合は、本Skillの所見にせず `validate-episode` の照合対象として報告する。

## 2. クラスタ走査

`cliche_check.py` の警告（話単位上限・近接密集・場面末尾）に対し、機械が拾えない4点を目視する。判定基準と改稿の序列は `guidelines/05-ai-guardrails.md §3-4` が正本。

| 目視項目 | 見るもの | 判定 |
|---|---|---|
| 場面テスト | その表現が更新するのは場面（視点人物の知覚・判断・行動・関係・利害）か、文飾か | 文飾なら優先度を上げる。直叙に戻して情報が減らないなら文飾 |
| 人物間共有 | 同じクラスタが複数人物の視点・台詞に出るか | 1人の癖なら許容候補、複数人なら均一化として優先度を上げる |
| 説明の二重化 | 台詞・動作の直後に地の文が感情名・理由・一般論で再説明 | 同じ意味を担う文を特定し、片方の削除を所見にする |
| 複合発火 | 胸の奥＋何か／所作＋わずかに／一拍＋静か＋決意／否定対句＋場面締め／圧縮癖＋比喩 | 単独警告より優先度を上げる |

警告ゼロでも、上限内で同じクラスタが毎話出続ける場合（話またぎの機能反復）は所見に含める。

## 3. 圧縮癖・装飾比喩の変種を拾う

`cliche_check.py` A2〜A7 は代表パターンしか拾えない。変種の発見は目視に頼らず、再現率優先の第1走査 `scripts/metaphor_sweep.py` を使う（正本 `guidelines/05 §2`。出力は候補であり警告ではない）。

```bash
python3 scripts/metaphor_sweep.py <対象ファイル>
python3 scripts/metaphor_sweep.py --all        # アーク境界・総合診断時
```

候補は場面テストで裁定し、修正するか `work/continuity/sweep-adjudicated.tsv` へ理由つきで登録する。繰り返し出る変種は `cliche_check.py` へのクラスタ追加候補として所見に含める。モチーフcensusの※印（所有者以外の視点話での使用）は人物間流用の疑いとして優先確認する。

## 4. 累積で確認する文体パターン

| シグナル | 対応 |
|---|---|
| 同じ決め台詞、否定対句、笑い方、締め方が反復する | 機能変化テスト（05 §3-4）にかける |
| 抽象動詞、同じ文末、同じ比喩が人物を跨いで続く | 均一化として優先度を上げる |
| 会話の声、敬語、呼称、感情時の崩れが全員同じ | 人物間の均一化。正典との照合は validate-episode へ |
| 同じ情報や場面を繰り返し、終了時の状態が変わらない | 水増し・停滞の所見にする |
| 固有比喩・象徴物が意味を変えずに再登場し続ける | 話またぎ計数（Full Detect §3）へ進む |

弱い項目は、同じ機能の近接共起または複数カテゴリへの広がりがあり、読者効果へ影響する場合にFull Detectへ進む。件数だけで進行を決めない。

## 5. 手順

1. スクリプトを実行し、[NG]と警告を引用する。正典・視点の疑いは validate-episode へ回す。
2. `cliche_check.py` の警告を目視4項目（場面テストを含む）で判定する。
3. 5系統の変種と、同じ語・構文・台詞・場面の反復を探す。
4. 作品意図、投稿先、allowlist・watchlist で誤検出を除く。
5. 強い局所事故または累積パターンがあればFull Detectへ進む。
6. 改稿依頼がある場合は引継ぎ票を作る。

## 6. 出力時の注意

- 「即ギルティ」「確定」「人間には不可能」を使わない。結果は観察事実と読者影響で説明する。
- タイプミスを残す・増やす・証拠として保存する提案をしない。
- 実在作者への告発、ミュート、通報、晒しを推奨しない。
