# 02. 視点・地の文・五感・台詞・口調

読者が機械的・平坦と感じる大きな要因は、文体・描写・台詞が場面や人物を越えて均一なことにある。本ファイルは、視点人物の偏り、具体的な判断、会話の含意を地の文へ戻すための規則を定義する。

---

## 1. 視点設計（三人称多元）

### 1-1. 本リポジトリの既定形式：三人称多元

三人称多元＝**場面内は厳密な三人称一元、場面間で視点キャラを交替させる連結方式**。「神の視点」（全知視点）ではない。

- 場面の内部では、カメラは視点キャラ1人の肩越しに固定する（三人称一元と同一の規律）。
- 視点の切替は**場面境界（`※　※　※` 等の場面転換記号）または章境界でのみ**行う。段落単位の切替は禁止。
- どの話・どの場面を誰の視点で書くかは `work/pov-plan.md`（視点運用表）で**執筆前に**決め、scene-card に転記する。
- POVキャラは「その人物にしか見えない情報・判断が物語に必要か」で絞る。人数を先に決めず、視点キャラ全員分の `character-sheet.md`（§視点フィルタ含む）を先に完成させる。

### 1-2. 視点ブレの禁則（場面内で絶対に守る）

守れている場面は次の形になる。**地の文に出てくる情報のすべてが、視点キャラがその瞬間に見た・聞いた・触れた・思い出したもののいずれかで説明できる。** 他人の内面は、表情、声、動作、間合いという観測可能なものを経由して読者へ届く。判断の言葉は視点キャラの語彙で書かれる。この形から外れたときが、下表の禁則に触れたときである。

| 禁則 | 理由 |
|---|---|
| 視点キャラ以外の内面描写を地の文に書く | 視点ブレ（head-hopping）。「彼女は不安を感じていた」（視点キャラ以外）はNG。多元視点の最重度違反 |
| カメラ位置を1段落内で動かす | 「アリスは部屋を見渡した。一方ボブはキッチンで」は別段落ではなく**別場面**にして視点を切替える |
| 視点キャラが知り得ない情報を地の文に出す | 「実はその時、隣の部屋で〜」型は禁止。別視点の場面として独立させる |

### 1-3. 視点キャラ以外の感情を描く方法

視点キャラ以外の心情を**外から推察する形**で描く：
- 直接：「彼女は悲しんでいた」（視点ブレ）
- 推察：「彼女の肩が小さく震えていた。視点キャラには、それが悲しみの兆しに見えた」（OK）

その人物の内面を直接書きたくなったら、それは**その人物を視点キャラにした場面を立てるべきサイン**。pov-plan.md に戻って場面割りを見直す。

### 1-4. 視点切替の作法

| 規則 | 内容 |
|---|---|
| 冒頭3文アンカー | 切替直後の最初の文〜3文目までに、新視点キャラの**名前＋固有の知覚・関心事**を置く（例：匂いに敏感なキャラなら匂いから入る）。読者に「誰の目か」を即座に確定させる |
| 地の文の声を変える | 語彙・文長・比喩の好み・注目対象を視点キャラごとに変える（character-sheet §視点フィルタに定義）。全視点が同じ声なら多元にする意味がない |
| 引きと受け | 別視点へ移る場合は、同じ情報を遅延させるだけでなく、別の利害・誤解・結果を受け渡す。焦らしを目的化しない |
| 同一シーンのリプレイ | 別視点で同じ場面を扱うのは、その人物にしか見えない情報または選択があり、再読部分より新しい意味が大きい場合だけ |
| 情報格差の管理 | 「誰が何を知っているか」を pov-plan.md の情報格差マトリクスで管理。視点キャラが知らないはずの事実を内心に混入させない。読者だけが知る状態（ドラマティック・アイロニー）は意図的にのみ作る |
| 切替頻度 | 話の長さではなく、視点変更によって得る情報・感情・利害が切替コストを上回るかで決める。同一視点の連続場面も普通に使う |

### 1-5. 地の文の人物名は中立呼称に固定する

地の文で人物の固有名を使う場合は、視点人物、相手役、目上、王侯を含む全員を**敬称・役職名なしの呼び捨て**で記す。視点人物の感情や上下関係で語りの呼称を変えない。

- 地の文：`アリシア`（OK）／`アリシア様` `アリシア殿` `アリシア王女`（NG）
- 身分を同時に示す必要がある地の文：`王女であるアリシア`のように、身分情報と中立の人物名を分ける。
- 台詞、作中の手紙・記録などの引用、明示的な内心の発話：character-sheetと正典の敬称・呼称に従う。
- 自由間接話法を含む地の文：視点人物の語彙や判断は反映しても、視点人物が使う敬称を固有名へ付けない。

役職・身分だけで人物を指す表現は固有人名ではないため本規則の対象外だが、読者が人物を取り違えず、正典上の役職と一致する場合だけ使う。

## 2. 地の文の作法

### 2-1. 説明動詞・説明形容詞の機能を確認する

| 反復時の確認語 | 見直し方 |
|---|---|
| 思った／感じた／考えた | 身体反応・行動・台詞・体言止めに変換 |
| 〜のようだった／〜のように見えた | 断定または描写 |
| 嬉しかった／悲しかった／悔しかった | 表情・身体・行動で示す |

例：
- Before：「彼は悔しいと感じた」
- After：「彼は唇を噛んだ。爪が掌に食い込む」

### 2-2. 抽象動詞の具体化候補

以下は単独でも自然な日本語である。近接反復して具体的な行為や結果を隠している場合だけ、場面に即した動詞へ直す。

| 抽象 | 具体例 |
|---|---|
| 整える | 並べる／揃える／直す／拭く／並べ替える |
| 削る | 切る／落とす／省く／消す |
| 回す | 配る／巡らせる／持ち回る |
| 揃える | 並べる／合わせる |
| 場を整える | （状況に応じて具体動作で書く）|
| 輪郭を持った | 形を成した／姿が見えてきた |
| 席を降りる | 役職を辞す／○○を譲る |

### 2-3. 文末リズム

過去形「〜た。」の連続は日本語小説で普通に成立する。長さ、主語、焦点、構文まで同型で続き、場面の速度や視点人物の声を平坦にしている場合だけ、文の結合、焦点変更、現在の知覚や会話への接続を検討する。現在形、体言止め、倒置を回数合わせで混ぜない。

例：
- Before：「彼は立ち上がった。窓を開けた。深く息を吸った。冷たい朝の匂いがした。」
- After：「彼は立ち上がる。窓を開け、深く息を吸った。冷たい朝の匂い。」

### 2-4. 「○年間」「○文字」型の数値表現

| 注意 | 内容 |
|---|---|
| 「○年間」 | 抽象的な年数表現は具体エピソードに（「あの夏から数えて」）|
| 「『ありがとう』その四文字に救われた」 | **必ず実文字数を数えて整合を取る**（「ありがとう」は5文字）|
| 「『はい』その三文字」 | 不整合（実2文字）。「その一言に」に書き換え |

### 2-5. 地の文と会話文の配分

配分はジャンルの固定比率ではなく、scene-cardの文体モードと場面の目的で決める。

- 地の文主体：知覚、判断、空間、因果を地の文で進め、台詞は選択や衝突が生じる箇所へ置く。
- 会話主体：応答連鎖で場面を進めつつ、話者、位置、身体、発話の結果を見失う箇所だけ地の文で接地する。
- 混合：説明量ではなく、認識の変化と対人上の変化に応じて配分を切り替える。

会話比率だけで良否を決めない。長い会話でも話者、空間、人物の選択、発話による状態変化が追えれば成立する。地の文が多くても同じ内容の説明を重ねれば冗長である。

### 2-6. 場面締めの一行警句を定型化しない

場面の最終行を「Xは、Yらしい」「Xは、Yの形をしている」「Xだけが、Yしていた」型の抽象警句で閉じる手法は、単発では余韻を作るが、毎場面続くと語り手の自動癖になり、読後感が均一化する（観点10・15）。

- 警句型の場面締めは1話に1回までを目安とし、残りの場面は動作、知覚、台詞、状態変化の具体で閉じる。
- 「〜の形」「〜らしい」などの抽象名詞化・推量による締めが近接反復していないか、話単位で確認する。
- 警句で閉じるかは、その場面の状態変化が要約を必要とするかで決める。直前の具体描写がすでに意味を運んでいるなら、警句は重複である。

### 2-7. 職能比喩の配分（知恵者系視点の飽和防止）

鑑定士、参謀、商人など評価・観察を職能とする視点人物では、計測・観測・査定の語彙（測る、物差し、値踏み、勘定など）があらゆる場面の結論へ流入しやすい。character-sheet §視点フィルタの「比喩の源泉」は比喩の**方向**の統制であり、**量**と**着地先**は本節で統制する。

- 職能語の本来領域（装備、商談、値付け、戦術など）では自由に使う。職能語は人物の芯であり、撤去しない。
- 感情・関係の決め所（慰め、救済、告白、悼み）への転用は1話1回までを目安とし、作中に実在する具体物（水晶の数値、ツケ帳など）へ接地している場合だけにする。
- 救済・慰めの台詞は、視点人物の職能語ではなく**相手の語彙圏**（相手の正典にある測定語・生活語・信仰語）から取る。例：「治す物差しじゃ、測れなかった」（視点人物の職能語）→「傷の治りだけ見てたんじゃ、分からなかった」と直し、相手の「届く」で受けさせる。
- 飽和しやすい語は character-sheet §視点フィルタの「飽和注意語」に定義し、`work/vocab-watchlist.tsv` へ転記して `scripts/vocab_check.py` で話単位の出現数を監視する。上限は現行本文の実測から決め（ラチェット方式）、超過の警告は採否を判断して、残す場合は除外欄へ理由つきで記録する。

## 3. 五感と身体性

### 3-1. 五感の配分ルール

五感は場面の判断、危険、欲求、記憶に効くものだけを選ぶ。全感覚を順番に埋めたり、各場面へ同数配置したりしない。
- 嗅覚：花・食事・汗・古い紙・雨後の土
- 味覚：飲食シーンで「甘い」だけでなく「舌に苦みが残った」等
- 触覚：服の質感・床の温度・髪の摩擦
- 温度／湿度：「冷たい朝」「肌に貼りつく湿気」
- 重量／圧：「肩にのしかかる」「胸を押される感覚」

### 3-2. 食事描写は固有名詞＋五感（観点14）

生活・食事が機械的・薄く見えやすい欠陥（観点14の確認一覧）：

| 確認候補 | 意図がなければ何が起きているか |
|---|---|
| 貴族の食事がスープとパンだけ | 身分、文化、当人の事情のどれにも接続しないと物量感が不足する |
| 主人公が高収入になっても古い家電を買い替えない | 金の使途、執着、倹約など理由がなければ生活変化が見えない |
| 冷蔵庫にミネラルウォーターしか入っていない | 欠乏や生活習慣の意味がなければ具体性が不足する |
| 主食が描かれない | 食事全体を見せる場面なのに欠けると生活像が曖昧になる |
| お惣菜だけが描かれる | 選択理由や食べ方に接続しないと商品名の列挙になる |
| 「お茶会ばっかりで、いつ家に帰ってるの？」レベルの生活描写の薄さ | 生活時間の流れが描けない |
| 料理シーンで「その材料でそれは作れない」 | 物理整合の欠如（卵白だけで全卵料理を作る等） |
| ドレスの素材と完成形が物理的に整合しない | 同上 |

食事が場面の選択、関係、階級、生活水準へ効くときは、次の素材から必要なものを選ぶ：
1. **固有食材・料理名**（「黒パン」「鴨のロースト」「林檎のコンポート」「白いんげん豆のスープ」「鹿の腿肉の岩塩焼き」「香辛酒で煮込んだ西洋梨」）
2. **調理法の具体**（「厚めにスライスした」「弱火で煮込んだ」「焼きたて」「半日塩漬けにした」「炭火で炙った」）
3. **嗅覚または味覚または触覚**（「シナモンの香り」「舌に絡む脂」「ナイフが沈む柔らかさ」「噛むと弾ける皮の張り」）

**判定基準**：その食事シーンが、作品の目的に応じて味・匂い・食感・物量・生活水準のいずれかを読者へ渡しているか。料理や食事が主題でない場面へ過剰な描写を義務づけない。

**冷蔵庫・パントリー・厨房の中身を描く場合**：品数をノルマにせず、その人物の生活、欠乏、余裕、準備不足のどれが伝わるかで選ぶ。空であること自体が具体的な意味を持つ場面もある。

### 3-3. 身体反応の語彙

感情を直接書かず身体で示す：
| 感情 | 身体反応の例 |
|---|---|
| 緊張 | 唇を噛む／喉が渇く／指先が冷える／鼓動が速い |
| 怒り | 拳を握る／頬が熱い／声が低くなる／息を詰める |
| 悲しみ | 喉の奥が熱い／視界が滲む／呼吸が浅い／肩が落ちる |
| 喜び | 頬が緩む／息が抜ける／背筋が伸びる |
| 恐怖 | 背筋が凍る／膝が震える／呼吸を止める |

身体反応は感情語の置換辞書ではない。人物の体質、抑制、状況に固有で、行動や判断へ影響する場合に使う。上の表は生理反応の記述であり、部位を発話・思考の主体にする代理主語（「目が言った」型）とは別物である。代理主語・装飾比喩の禁止は `05-ai-guardrails §3-5` を正本とする。同じ場面に身体反応が複数並んだら、次の行動・判断を実際に歪めた方だけ残す（05 §3-4 場面テスト）。

## 4. 会話・台詞

### 4-1. 口調の固定

各キャラの以下を `character-sheet.md` に固定し、章を跨いで一貫させる：
- 一人称：俺／僕／私／自分／拙者／…
- 二人称：おまえ／あなた／君／てめえ／…
- 語尾：〜だ／〜だぜ／〜ですわ／〜なのよ／〜じゃ／…
- 敬語の使い分け：誰に対して敬語／タメ口か
- 禁則語：このキャラは絶対に言わない言葉（例：寡黙キャラなら長台詞禁止）
- 口癖：必要な人物だけ。固定句ではなく、情報の選び方や応答の癖でも声を分ける

### 4-2. 短文棒読みの回避

会話が機械的に見えやすい欠陥：寡黙ヒーローが「ああ」「それでいい」「構わない」しか言わない。

対策：
- 短文の応酬が位置、利害、含意を失っている場合は、必要な発話または動作を足す
- 寡黙設定でも、行動・視線・身体反応で内面を補う
- 関西弁などの方言は、書ける場合のみ使う。中途半端な方言は事故になる

### 4-3. 感情による声の変化

感情が高まっても全員が同じ崩れ方をするとは限らない。人物に応じて、語彙の狭まり、沈黙、言い直し、過剰な丁寧さ、早口などに差を出す：
- 「うるさい！」「やめてよ！」「もう嫌……」
- 言いかけて止まる、繰り返す、ど忘れする
- 文法が崩れる：「だ、だって、私は……」

### 4-4. どもりの正書

漢字の読みを正確に拾う：
- **正**：「こ、今度はちゃんとしてくれ」（「こんど」のC）
- **誤**：「い、今度はちゃんとしてくれ」（「今度」の読みの頭音と一致しない）

### 4-5. 同一発言は1つの「」にまとめる

| ダメ | OK |
|---|---|
| 「○○がありました」「だけど誰も確認はしなかった」 | 「○○がありました。だけど、誰も確認はしなかったんです」 |

文ごとにカギ括弧を分割しない。1人の連続発言は句点で繋いで1つの「」内に収める。

### 4-6. 笑い方・泣き方の単調化を避ける

「はっはっは！」「うふふ」「ふふふ」を全キャラ・全場面で同じに使い回さない。笑う理由、抑え方、相手との関係が見えるようにする：
- A：「はっ」と短く
- B：肩で笑う（地の文のみ）
- C：「あはははっ」と崩れる

### 4-7. 会話違和感パターン一覧（観点7）

ai-novel-detector の観点7（会話・セリフの違和感）の禁則を網羅する。各章の出力後に**全項目をスキャン**する：

| 違反パターン | 該当例 | 対策 |
|---|---|---|
| 1行短文の応酬で完結 | 「頼めるか」「大丈夫です」「助かる」 | 会話が変えた関係・判断・位置を補う。`§4-2` 参照 |
| 熱血タイトルなのに本文の主人公が「いつもどおりです」「わかりました」しか言わない | タイトルと本文のトーン乖離 | タイトル決定時に**期待トーン**を `plot.md §作品基本情報` に明記し、本文の語彙密度を合わせる |
| 同じ人物の口調が常体↔敬語、男性↔女性で揺れる | キャラシート未参照 | 当該人物の `character-sheet.md §言葉遣い` を執筆前に読む |
| 身内に丁寧語が混じる（夫婦・親子間で「〜ですね」連発）| 敬語ライン未設定 | `character-sheet.md §敬語ライン` で「身内＝タメ口、外＝敬語」のように明示 |
| 全人物が感情場面でも同じ調子を保つ | 声と反応の平坦化 | `§4-3 感情による声の変化` を参照 |
| どもりがおかしい：「い、今度はちゃんとしてくれ」 | 読みの頭音との不一致 | `§4-4 どもりの正書` 参照。実際の読みの頭音を取る |
| 同一発言が文ごとにカギ括弧で分割される | 「〜がありました」「だけど誰も〜」 | `§4-5` の通り1つの「」内に句点で繋ぐ |
| 近しい人物の会話が情報交換だけで終わる | 「○○は守る」「ああ」 | 共有履歴、言わずに済ませる部分、相手だけに見せる反応のいずれかを検討する |
| 主治医・上司のような指導役キャラが**同じ展開・同じ台詞**を繰り返す | 過去の会話履歴を未参照 | 章を跨ぐ会話履歴を `world-bible/log/canon-log.md` で管理し、必要箇所を執筆前に読む |
| 関西弁・方言が中途半端で事故になっている | 書けないのに使った | `§4-2` の通り、書けないなら使わない |
| 携帯小説のモノローグ風の地の文 | 「〜と思った」連発／一文一段落 | `§2-1, §2-3` の通り過去形連続を崩す |
| 指示台詞が仕様記述になっている | 「刃に濃いめに注げ」型のパラメータ直結命令 | `§4-8 音読テスト` |
| 全人物が警句・箴言でオチを付ける | モブの店主・職人まで名言を言う | `§4-9 警句密度` |

### 4-8. 指示・命令台詞は音で書く（設計書言語の禁止）

戦闘・作業中の指示台詞は、書き言葉として整合する文ではなく、その場で叫べる音として書く。判定基準は**音読テスト**：切迫した場面の台詞を声に出したとき、指示書の読み上げに聞こえたら書き直す。

| ダメ | 何が起きているか | OK |
|---|---|---|
| 「刃に濃いめに注げ」 | 能力の運用パラメータ（濃度）を副詞で命令形へ直結。修飾語の語感（茶を淹れる）も場面と衝突 | 「（相手の名）、もっと濃く！　刃だ！」 |
| 「灯りをナイフに、薄く保て」 | 目的語・様態・動詞が仕様記述の語順のまま | 「ナイフの灯り、切らすなよ。薄くていい」 |
| 「小さく、多く、絶やさず」 | 三連スローガン。標語であって発話ではない | 指導場面で教えとして確立し、戦闘中は断片で引用する（「撃つな。割れ！」） |

- 切迫度が上がるほど、助詞・目的語の脱落、呼びかけ、言い直しを増やす。完全な文で怒鳴る人間はいない。
- 作中造語の指示語（例：「注げ」）は、初出の指導場面で意味を確立してから短く使う。確立済みの造語自体は保持してよい。修飾を足すときは、日常語の語感（飲食・家事の副詞など）と場面が衝突しないか確認する。
- 三項句（「AをB、CをD、EをF」）のリズムは機械的文章の典型で、台詞では原則使わない。使うのは、作中で確立した教え・経典・口上の引用として初出と変奏が設計されている場合だけとする。

### 4-9. 警句の密度を配分する（全員に名言を言わせない）

台詞の警句（倒置オチ、対句、体言止めの箴言）は、一つ一つの完成度が高くても、密度が上がると全人物が同じ知性で喋る作品になる（観点10・11）。完成度ではなく密度と分布を管理する。

- 1場面の台詞の警句は、中心人物あわせて1つまでを目安とし、決め場面に取っておく。
- 名前のない係、店主、職人などの脇役は、原則として警句を言わない。実務的な発話、凡庸な相槌、言い差しで応答させる。脇役に格言を言わせるのは、その人物を立てる設計があるときだけにする。
- 各話に最低1箇所、オチのない発話を意図的に残す（外し球）。言い淀み、単純な事実確認、答えになっていない返事など。会話の全応酬がオチで終わっていたら、どこかを外す。
- 警句を削る優先順位：脇役の警句 → 同一場面の2つ目以降 → 地の文の締め警句（`§2-6`）と近接しているもの。

## 5. 決め台詞・反復フレーズ

### 5-1. 決め台詞の変化を追う

- 決め台詞は回数で合否を決めず、初出、反復、意味の反転、回収の各場面で役割が変わるかを見る。
- 相槌や儀礼句と、作品固有の反復句を分ける。
- 反復しても場面の意味が増えない場合は削るか、人物の変化に合わせて崩す。

### 5-2. 定型化しやすい反復フレーズ（要文脈確認）

以下は単独では自然な表現であり、禁止語ではない。近接して反復し、人物や場面を替えても同じ機能で使われる場合に見直す：
- 「これでいい」
- 「○○ではない、それだけで十分だった」
- 「これは叱責ではない、ただの確認の言葉だ」
- 「最高の光栄です」
- 「数字／帳簿は嘘をつかない」
- 「○○……はっはっは！」型の同一笑いの全キャラ展開

### 5-3. 話またぎの逐語反復（機械検査あり）

モチーフ・天丼・対句の再登場は変奏を必須とする。語順、長さ、視点、係る対象のどれかを変え、逐語のままでは再利用しない。逐語一致は変奏ではなくコピペに見える（観点6）。

- 話をまたぐ12字以上の逐語一致は `scripts/repeat_check.py` が警告する。
- 警告への対応は2択とする。(1) 変奏する。(2) 意図的な定型（システム表示、儀式文、決め口上）として `work/continuity/phrase-allowlist.txt` へ理由の注釈つきで登録する。
- 登録の前に、その反復が §5-1 の判断基準（再登場で意味・関係・状況が変わるか）を満たすことを確認する。警告を消すためだけに登録しない。

## 6. 描写と説明の使い分け

### 描写（show）
- 五感・身体・行動・台詞で間接的に伝える
- 読者に解釈の余地を残す

### 説明（tell）
- 直接的な情報伝達
- 「彼は怒っていた」「○○は△△の組織だ」

### 配分
- 描写と説明は比率で合否を決めない。場面の焦点、速度、読者が既に知ることに応じて選ぶ
- 説明は必要な判断に結びつけ、既出情報を同じ形で繰り返さない
- 感情・関係性は、重要な変化では行動、知覚、台詞の含意を優先する。要約が速度を保つ場面では説明も使える
