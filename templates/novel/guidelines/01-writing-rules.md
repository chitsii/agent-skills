# 01. 記号・正書法・改行・ルビ・括弧

日本語Web小説（なろう・カクヨム）で実務的に守るべき表記規則を定義する。AI生成で頻繁に事故が起きる箇所を**禁則**として明示する。

---

## 1. 三点リーダ「……」

### 規則
- **「……」（U+2026 を2つ連続）に統一**
- **偶数個**（基本2つ。情感を強める場合は4つ＝「…………」）。奇数個は使わない
- 文末三点リーダの後の句点は**派閥を作品冒頭で決め最後まで貫く**：
  - 派閥A：「……」のみ（句点なし）
  - 派閥B：「……。」（句点あり）
  - **混在禁止**

### 禁則
| ダメ | OK |
|---|---|
| `…` 1個 | `……` |
| `…………` | （4つ＝可、ただし多用しない）|
| `・・・` | `……` |
| `...`（半角ピリオド3つ）| `……` |
| `．．．`（全角ピリオド3つ）| `……` |
| 「マジかよ……本当に効いた……！」（接着剤的多用）| 「マジかよ。本当に効いた……！」|

**接着剤的な多用を避ける**：三点リーダを文と文を繋ぐパテのように使わない。沈黙、躊躇、途切れの機能が同じまま反復していないか文脈で確認する。

---

## 2. ダッシュ「――」

### 規則
- **「――」（U+2015 を2つ連続）に統一**（2倍ダーシ）
- **偶数個**（基本2つ。長く伸ばす場合は4つ＝「――――」）
- 文末ダッシュの後の句点処理は三点リーダ同様、作品冒頭で派閥決定

### 禁則
| ダメ | OK |
|---|---|
| `ー`（長音記号1つ）| `――` |
| `ーー`（長音記号2つ）| `――` |
| `──`（罫線）| `――` |
| `—`（emダッシュ1つ）| `――` |
| `--`（半角ハイフン2つ）| `――` |
| `—-` 混在 | `――` |

---

## 3. 句読点「、」「。」

### 規則
- 一文が複数の焦点を抱え、主述や時間関係を追いにくい場合は文を切る。句点数だけで分割しない
- 短文中央の不要な「、」を入れない
- リズムを取るための「、」は段落内で揺らす（同位置に毎文打たない）

### 禁則
| ダメ | OK |
|---|---|
| 「Aは、Bだ。」（短文に不要な読点）| 「AはBだ。」 |
| 「彼は、立ち上がり、窓を、開けた。」（過剰）| 「彼は立ち上がり、窓を開けた。」|
| 同じ長さの短文が続き、意図せず過呼吸になる | 意味のまとまりと場面速度に合わせて結合・分割する |

---

## 4. カギ括弧「」『』

### 規則
- **会話**：`「〜」`
- **会話内引用・書名・固有名詞強調**：`『〜』`
- **入れ子**：`「〜『〜』〜」`
- **同時発話・複数人**：`「「〜」」` `「「「〜」」」`（開閉個数を一致）

### 句点ルール（重要）
- **閉じカギ直前に句点「。」を付けない**：「おはよう」が標準。「おはよう。」は出版慣行外
- **「！」「？」の後にも句点を付けない**：「やめろ！」が標準。「やめろ！。」は誤り
- **読点「、」**は閉じカギ前でも付けない：「行こう、」とせず「行こう」

### 禁則
| ダメ | OK |
|---|---|
| 「行ってきます。」 | 「行ってきます」 |
| 「うるさい！。」 | 「うるさい！」 |
| 同一発言が2つの「」に分割：「○○がありました」「だけど誰も確認しなかった」 | 1つの「」にまとめ「。」で繋ぐ：「○○がありました。だけど誰も確認しなかった」|
| 強調 `"覚醒"` | 『覚醒』 |
| 開きっぱなしのカッコ | 必ず閉じる |
| ` 『○○ 』`（全角スペース付き）| `『○○』` |

---

## 5. スペース

### 規則
- **本文中の半角スペースは原則禁止**
- 必要なら全角スペース（場面区切り・タイトル等）
- 例外：英数字直後の慣例位置（例：`50 km`）

### 禁則
| ダメ | OK |
|---|---|
| 「彼は 静かに 言った」 | 「彼は静かに言った」または「彼は、静かに言った」|
| 「私は その時、 驚いた」 | 「私はその時、驚いた」 |

**判定法**：日本語の文字（ひらがな・カタカナ・漢字）に挟まれた半角スペースは**全部削除または読点化**。

---

## 6. 全角・半角

### 規則
- **本文**は原則全角（英数字・記号も含む）
- 縦書き想定なら必ず全角
- 横書きWebでも文芸的本文は全角統一が無難

### 禁則
- 半角数字を本文に出す：`50年` → `五十年` または `５０年`
- 半角アルファベットを本文に出す：`elegant` → 削除または「優雅な」に置換
- emダッシュ `—`、罫線 `─`、長音以外の `―` を区別せず使う

---

## 7. 段落・改行・空行

### 規則（Web小説標準・スマホ可読性を最優先）

Web投稿ではスマートフォンの縦スクロールでも読める段落設計を確認する。空行は、話者、意味段落、場面転換、余韻を区別するために使い、行数を増やすこと自体を可読性とみなさない。投稿先のプレビューで、詰まりすぎと分断しすぎの両方を点検する。

- **段落冒頭は全角1字下げ**（会話文行は字下げしないのが慣例）。
- **地の文の意味段落の切れ目で空行1行**を基本とする（数文ごとに改行＋空行で画面を軽くする）。
- **地の文 ⇄ 会話文の切り替わりでも空行1行**を入れてよい（話者・場面の転換を視覚的に示す。Web小説で広く使われるリズム）。
- **連続する会話の応酬（同一場面の掛け合い）は空行で割らず詰める**（テンポを出す）。
- **時間飛躍・大場面転換**は、作品で固定した場面転換記号または意味のある空行で示す。空行数を強度表現の段階表にしない。
- **緩急をつける**：間を取りたい所で空け、畳みかけたい所で詰める。空行そのものが「沈黙・余韻」の演出になる。

### 禁則（AI事故）
| ダメ | OK |
|---|---|
| **全行・全段落を均一に空行で割る**（生成AI出力をWord経由でコピペした痕跡。機械的で単調）| 意味のまとまり・話題転換・余韻の所で空け、掛け合いは詰める＝**緩急** |
| 会話の応酬まで一行ごとに空行でバラす | 同一場面の連続会話は詰める |
| 空行ゼロでびっしり詰める（書籍組版のままWebに出す）| スマホ前提で段落間・話者転換に空行を入れて軽くする |

**要点**：Webでは「空行を使う／使わない」の二択ではなく、**空行を使いこなして緩急を作る**のが正解。均一に空けるのも、全く空けないのも、どちらも不自然。

### 1話の長さ
- **作品ごとの正本は `work/plot.md` §作品基本情報の「1話の目安字数」**。投稿先での表示、更新頻度、ジャンルの読み味、場面の自然な切れ目から目安と許容幅を決める
- 市場の現在値を根拠にする場合は取得日と標本を記録し、全サイト共通の固定字数として扱わない
- 長さを揃えるために場面を水増し・切断しない。大きく外れた話は、場面機能が過密または不足していないかを確認する
- 話末は、次への圧力だけでなく、小さな決着、安堵、関係の含意、余韻も選べる

### 空行の機械検査・正規化（観点21対策。用途を間違えないこと）
- **新規ドラフトの検査**：`scripts/normalize_blanklines.py --check <ファイル>` で空行4行以上の連続を検出する（検出のみ・書き換えない）。文体モードにかかわらず、間と余韻は意味段落と空行1行を基本に作り、空行数を機械的な強度表現にしない
- **Webペースト由来の持ち込み本文の正規化**：`scripts/normalize_blanklines.py <入力> [<出力>]`（N行連続空行→N−2行に圧縮）
- **正規化を新規ドラフトに掛けてはいけない**：1行空行が密着に潰され、1段落1空行のリズムが壊れる

## 8. ルビ記法

### カクヨム
| 用途 | 記法 | 例 |
|---|---|---|
| ルビ（漢字・漢字以外とも）| `|親文字《ルビ》` | `|異界《いかい》` `|神無瀬《かみなせ》` `|時空《とき》` |
| 傍点 | `《《対象》》` | `《《これは罠だ》》`（ルビと同時不可。先頭に `|` は付けない）|

### なろう
| 用途 | 記法 | 例 |
|---|---|---|
| ルビ | `|親文字《ルビ》` または `親文字(かな)` | `|異界《いかい》` `|神無瀬《かみなせ》` `異界(いかい)` |
| 制限 | 親文字10字以内・ルビ20字以内 | — |

### 規則
- **親文字の直前に必ず半角縦線 `|` を置く**。漢字のみの親文字（例 `神無瀬`）でも省略しない。`神無瀬《かみなせ》` は不可、`|神無瀬《かみなせ》` が正しい。
  - 理由：`|` を省くと、親文字に隣接する漢字までルビ範囲に巻き込まれる（例 `旧神無瀬《かみなせ》` が「旧神無瀬」全体にルビが乗る）。`|` で親文字の開始位置を明示すれば、どの位置でも安全かつ一意に振れる。
  - 例外：傍点 `《《対象》》` には `|` を付けない。
- 投稿先を作品開始時に決定し、**該当記法のみ**で書く
- 固有名詞は初出にルビ、以降は省略
- 全漢字にルビを振らない（読みづらい）

## 9. 他言語文字混入の禁止（最重要）

### 規則
本文に以下の文字種を**絶対に出さない**：
- ハングル：`가-힣` `ㄱ-ㅎ` `ㅏ-ㅣ`
- ギリシャ文字：`Α-Ω` `α-ω`（数学記号として意図的に使う場合を除く）
- キリル文字：`А-Я` `а-я`
- アラビア文字、ヘブライ文字、その他非ラテン非和文字
- 突発的な英単語混入：「彼女はelegantに微笑んだ」型

### 検出（生成後に必ず実行）
```bash
# ハングル検出
grep -P '[\x{AC00}-\x{D7A3}\x{1100}-\x{11FF}]' 本文.txt
# ギリシャ文字検出
grep -P '[\x{0370}-\x{03FF}]' 本文.txt
# キリル文字検出
grep -P '[\x{0400}-\x{04FF}]' 本文.txt
```

1文字でも検出されたら、物語上の必然があるか確認し、意図しないものは**全てを日本語に置換**する。原因は入力・変換・OCR・コピペ・文字化け・生成など複数あり得るため断定しない。

## 10. 縦書き／横書きでの差

| 項目 | 縦書き（書籍・縦書きビューア）| 横書き（一般Web）|
|---|---|---|
| 数字 | 全角または漢数字 | 全角推奨 |
| 三点リーダ・ダッシュ | 偶数個必須（縦中央通し） | 偶数個推奨 |
| `！？` の後の全角スペース | 入れる派が多い | 出版社・媒体により異なる |
| 半角英数 | 縦中横が必要なため避ける | 必要最小限なら可 |

**作品開始時に投稿先と派閥を決定し、`world-bible.md` に明記する**。
