# 05. 機械事故と定型化候補のガードレール

執筆中・執筆後に確認する項目を、機械的に確定できる違反と、文脈を読んで判断する改稿候補へ分ける。語句の出現だけから著者性を推定せず、自然な日本語を検出器対策のために歪めない。

役割分担は、本ファイルと `scripts/check.sh` が機械規則の正本、`ai-novel-detector` が文章・文体の診断・改稿優先度・引継ぎ票（正典・構造の照合は `validate-episode`、外部作品の総合評価だけ28観点）、`humanize-ai-writing` が実際の本文改稿とする。診断Skill内へ本ファイルの規則を重複実装しない。

## 2. 検出スクリプト

機械検出の**実装の正本は [`scripts/check.sh`](../scripts/check.sh)**（16セクション。本章の§1対応表・§3候補一覧に対応）。検出パターンをここに再掲しない（二重実装のドリフト防止）。

```bash
./scripts/check.sh work/drafts/episode01.txt              # 単一ファイル
./scripts/check.sh --strict work/drafts/*.txt             # 違反があれば exit 1（CI・フック向け）
./scripts/check.sh --section lang work/drafts/episode01.txt   # 他言語混入のみ
./scripts/check.sh --help                                 # セクション名一覧
```

検出パターンを追加・変更するときは `check.sh` を直接編集し、必要なら本章の対応表（§1）と28観点逆引き表（§7）を更新する。

話またぎの逐語反復（単一ファイル検査の `check.sh` では見えない）は **`scripts/repeat_check.py` が実装の正本**。

```bash
python3 scripts/repeat_check.py work/drafts/episode012.txt   # 対象話 vs 既存全話
python3 scripts/repeat_check.py --all                        # 全話総当たり
python3 scripts/repeat_check.py --strict --all               # 未処理の警告があれば exit 1
```

出力は[警告]であり、[NG]と違って機械的な合否ではなく採否判断の対象である。意図的な定型（システム表示、儀式文、決め口上）は `work/continuity/phrase-allowlist.txt` へ理由の注釈つきで登録して抑止する（02 §5-3）。

作品固有の職能語・口癖の飽和（`check.sh §11` の汎用クラスタでは監視できない語）は **`scripts/vocab_check.py` が実装の正本**。監視語と話単位の上限は `work/vocab-watchlist.tsv` に置き、設計は character-sheet §視点フィルタ「飽和注意語」から転記する。

```bash
python3 scripts/vocab_check.py work/drafts/episode012.txt   # 対象話のみ
python3 scripts/vocab_check.py --all                        # 全話
python3 scripts/vocab_check.py --strict --all               # 未処理の警告があれば exit 1
```

超過の警告は採否判断の対象である。意図的な密度で残す話は watchlist の除外欄へ理由つきで記録する（02 §2-7）。

英語圏フィクション由来の直訳クリシェ（作品を問わず汎用のクラスタ）は **`scripts/cliche_check.py` が実装の正本**。クラスタ定義・話単位上限・近接密集・場面末尾の3軸をスクリプト内に置き、許容条件と改稿方針は §3-4 を正本とする。

```bash
python3 scripts/cliche_check.py work/drafts/episode012.txt
python3 scripts/cliche_check.py --all                        # 全話
python3 scripts/cliche_check.py --strict --all               # 未処理の警告があれば exit 1
python3 scripts/cliche_check.py --selftest                   # パターン回帰テスト
```

警告は採否判断の対象。人物の癖・作品モチーフとして残す場合は `work/continuity/cliche-allowlist.txt` へ「クラスタID・ファイル名またはALL・理由」で登録して抑止する。

圧縮癖・装飾比喩の**見落とし確認**（再現率優先の第1走査）は **`scripts/metaphor_sweep.py` が実装の正本**。`cliche_check.py`（適合率優先・警告0ゲート）と二層構造をなし、sweepの出力は**候補**であって警告ではない。一致だけを根拠に修正せず、§3-4の場面テストで採否を決め、残置は `work/continuity/sweep-adjudicated.tsv` へ理由つきで登録して抑止する。人物別モチーフの全話横断censusは `work/motif-dictionary.tsv` と `work/pov-plan.md §2` の視点割当を突き合わせ、所有者以外の視点話での使用（人物間流用の疑い）を示す。

```bash
python3 scripts/metaphor_sweep.py --all                  # 全話スイープ＋モチーフcensus
python3 scripts/metaphor_sweep.py --all --compare <旧drafts>   # 改稿前後の解消/残存/新規
python3 scripts/metaphor_sweep.py --selftest             # パターン回帰テスト
```

使いどころ：アーク境界・総合診断・大規模改稿の後（毎話の検証ループでは`cliche_check.py`だけでよい）。改稿の完了報告では、sweep残余が全件裁定済み（修正または登録簿記載）であることを確認する。

## 3. 定型化候補

以下は自然な日本語にも現れるため禁止語にしない。近接反復、複数人物での使い回し、具体的な行為や判断の代替になっている場合だけ改稿候補とする。

### 3-1. 抽象動詞（具体動詞に置換）

| 抽象語 | 置換候補 |
|---|---|
| 整える | 並べる／揃える／直す／拭く／並べ替える／磨く |
| 削る | 切る／落とす／省く／消す／削除する |
| 回す | 配る／巡らせる／持ち回る／回転させる |
| 揃える | 並べる／合わせる／一致させる |
| 場を整える | （状況に応じて具体動作で書き直す）|
| 輪郭を持った | 形を成した／姿が見えてきた／像を結んだ |
| 席を降りる | 役職を辞す／○○を譲る／辞任する |
| 役を降りる | 同上 |

### 3-2. 近接クラスタの確認

次のような抽象語・事務語・雰囲気語が狭い範囲に集まり、どの人物・場面でも同じ働きをしていないか確認する：
- 帳簿／整理／書類／記録／監査／外交／役割
- 礼節／秩序／構造／裁定
- 銀木犀／輪郭／空気／場所／席
- 一拍／静けさ

「経理を題材にした作品」など作品設定上必然な場合は使用可だが、**装飾語として使わない**（ストーリーに必要なときだけ）。

### 3-3. 定型化しやすいフレーズ（要文脈確認）

| 確認するフレーズ | 見直す条件 |
|---|---|
| 「○○は嘘をつかない」 | 複数作品・人物で同じ決め台詞として使う、または具体的な根拠を置き換えている |
| 「それだけで十分だった」 | 直前の具体物がなく、小結として何度も場面を閉じる |
| 「○○ではない、それだけで十分」型 | 否定対句が近接し、人物固有の判断を均一化する |
| 「これは叱責ではない、ただの確認の言葉だ」 | 語り手が行為の意味を先回りして説明している |
| 「最高の光栄です」 | 人物・制度・場面に対して不自然な直訳調になっている |
| 「私の心はもう動かない」 | 結末の感情を具体的な選択や関係変化なしに要約する |
| 「感情ではなく整理です」 | 抽象語で対立や身体反応を回避する |
| 「○○の物差しで測る／測れなかった」型 | 慰め・救済・評価の場面で、人物を替えて同じ計測比喩が反復している。作中に実在する計測（水晶の数値等）へ接地した1回を残し、他は各人物固有の語彙圏（正典の測定語・生活語）で言い直す |
| 「○年間」 | 年数が記憶、経歴、現在の選択へ接続していない |
| 「全部を渡す」 | 何を、どの行為で、どの代償とともに渡すか不明 |

キャラ名は語単体で警戒せず、作品内の言語体系、音の識別性、家名・地域・階級との整合で判断する。

### 3-4. AIクリシェクラスタ——場面テストと改稿の序列

英語圏フィクションの直訳クリシェと感情ぼかしは、単語一個ではなく**頻度・人物間共有・場面末尾での使用・「何か」のぼかし**の組合せでAI臭を生む。機械検出の正本は `scripts/cliche_check.py`（クラスタ定義と検出閾値を内蔵）。**検出閾値は警告のトリガーであり、作文時の割当量ではない**。「1話に○回まで使える」と読み替えて上限まで配置しない。

**場面テスト（採否判断の正本）**：その表現が更新するのは「**場面**」か、「**文飾**」か。

- **場面を更新する**：視点人物の知覚・判断・行動・関係・利害に、直叙では伝わらない情報を足している。→残してよい。
- **文飾を更新する**：文章を文学的に見せる操作だけで、直叙に戻しても場面の情報が減らない。→直叙化するか削除する。

| 系統 | 代表 | 許容条件（場面テストの適用） |
|---|---|---|
| B 身体反応 | 胸の奥で何かが／心臓が跳ねた・早鐘／止めていた息／涙が頬を伝う／拳を握りしめる／頭が真っ白 | 感情名の代理ではなく、次の行動・判断を実際に変えている。同じ場面に複数並んだら、行動を歪めた方だけ残す |
| A 所作ビート | 目を細めた／眉をひそめた／肩をすくめた／口の端が持ち上がった | 動作が会話の機能（疑う根拠・手元の作業）に接続している。人物別の頻度差が設計されている |
| E 感情抽象化 | 言葉にできない何か／安堵と寂しさが入り混じる／わずかに・そっと・ゆっくりと／静かな決意／声の温度・感情の輪郭 | 未命名であることそのものが場面の主題になっている。「静かな」「わずかに」は削って意味が変わらなければ削る |
| R 構文 | 否定対句／それだけで十分だった／一拍おいて／という名の | 人物がその論理形式で考える設計がある（§3-3と同基準） |
| V 語彙 | 羅針盤・タペストリー・運命の糸・歯車／紡ぐ・彩る・染め上げる | 人物の職能・生活圏に実在する道具で、場面の核を担っている |
| D/S 台詞・締め | 〜だろう？の付加疑問／人は〜ものだ・本当の〜を知った | 台詞は人物固有の語尾設計に従う。教訓での場面締めは原則回避（02 §2-6） |
| A2〜A7 圧縮癖・装飾比喩クラスタ | 商人でない口で答えた／仕事の顔で言う／卓が笑った／保留の棚／噂が営業中 | 代理主語・名詞貼り付け・物品管理化・擬人化。定義・例・許容条件は **§3-5 を正本**とする |

**改稿の序列（削除→直叙→接地）**：警告箇所と目視で見つけた文飾は、この順で試す。**埋める前に削る。**

1. **削除**：その文（または比喩部分）ごと削って前後を読む。場面が立つならそれで終わり。
2. **直叙**：人物を主語に戻し、動作・発言・手つき・口調で直接書く（「先輩の顔で講釈を垂れた」→「先輩ぶって講釈を垂れた」、「三層は、別の顔をしていた」→「三層は、別物だった」）。
3. **接地**：削除でも直叙でも場面の情報が失われるときだけ、次の材料で書き直す。材料が正典・場面にないなら新造せず削除へ戻る。
   - **具体物への注意移動**：その人物だけが気にする物・音・距離へ（「返事の代わりに湯呑みを置いた。底が卓に当たり、思ったより大きな音がした」）
   - **判断・動作の失敗**：感情を判断の歪み・手順の失敗として（「三度読んだ帳簿の同じ行を、まだ読んでいた」）
   - **利害への還元**：何を失うと恐れたか・何を期待したかを1つ決めて示す（台詞＋「まだ返していない合鍵をポケットで握った」）
   - **人物固有比喩（最後の手段）**：職能・土地・身体経験の語彙圏に限定し、場面の核を担うときだけ。第一候補にしない——固有比喩で埋める癖は、直訳クリシェを消した穴に自作クリシェを充填する（§3-5系統5）

**機能変化テスト（反復モチーフの採否）**：同じモチーフ・比喩・決め台詞の再登場は、**前回から意味・関係・状況が変わっているときだけ**残す。同じ機能の反復は、初出と機能が変わる回を残して間を削る。回数を数えるのは検出スクリプトの仕事であり、作文・改稿時に数値上限を割り当てない（上限いっぱいまで均等配置する癖を生むため）。

補助規則：台詞が強いなら地の文を削る（説明の二重化禁止）。表情の説明より返答の遅れ・語尾の崩れ・物との距離で示す。

### 3-5. 圧縮癖と装飾比喩の禁止——代理主語・名詞貼り付け・擬人化

**文章を文学的に見せるためだけの比喩・換喩・擬人化を使わない。** AI文体の中核にあるのは、人物・感情・状況を名詞へ圧縮して貼り付け、直叙を避ける癖である。長編1作分（数十万字・全話）の抽出調査で反復が確認された5系統を原則として避ける。個別の採否に迷ったら §3-4 の場面テストにかけ、改稿は削除→直叙→接地の序列で行う。

**系統1：役割・心理を「顔・声・目・手」に貼り付ける**

| 避ける例 | 直し方 |
|---|---|
| 商人の顔／開戦の顔／帳場の顔／世間話の顔／聞く側の顔／受付嬢の顔を置いてきた | その場の動作・表情・発言・口調で書く（帳面を閉じてから言う／帳場に立つときの口調で答えた） |
| 射手の声／商いの声／完璧な商いの声で応じた | 声の実際の変化を書く（早口になった／敬語が一段深くなった） |

**系統2：身体部位を独立した判断主体にする**

| 避ける例 | 直し方 |
|---|---|
| 青い目が言った／手が仕事をする／足が信じる／喉が正直／耳が数を数え | 人物を主語に戻す（彼女は目を逸らして言った／その人物が数を八と聞き分けた） |
| 壊れ物を扱う夜の手で／商人でない口で／庭師のような目で | 副詞句か「〜として」で書く（壊れ物を扱うつもりで／商人としてではなく） |

**系統3：心理・未解決事項を物品管理に置換する**

| 避ける例 | 直し方 |
|---|---|
| 保留の棚／棚に札が一枚増えた／札を指で倒した | 何を保留したか・いつまでに決めるかを内容で書く（答えの出ない問いは、夜まで置いておくことにした） |
| 皮肉の鎧を着直した／理屈の皮を被せる／商いの背骨 | 行動として書く（早口の皮肉に戻った）。抑制・強がりは理由（誰に悟られたくないか）で示す |

**系統4：無生物に人間の動作をさせる**

| 避ける例 | 直し方 |
|---|---|
| 卓が笑った／空気が笑いで戻る／物が住人の名を語る／部屋が仮住まいの顔をやめた | そこにいる人間の動作に戻す（卓の全員が笑った） |
| 噂が走る・歩く・営業中・先に着いていた／地図・看板が育つ／町が送り出している | 知覚の主体を人間へ戻す（検問へ戻ると、もう昨日の話が出ていた／地図の余白が埋まっていく） |

**系統5：人物固有モチーフで心理説明を代替する**

| 避ける例 | 直し方 |
|---|---|
| 弓手の感情・言葉・選択を矢・弦・矢筒で語り続ける／全感情を職能語で置換する | 固有比喩は場面の核を担う箇所だけに置き、再登場は機能変化テスト（§3-4）を通す。感情の推移そのものは動作・台詞・判断の変化で書く |

補助の型：「〜の見本のような顔で」は直叙する（開き直った顔で）。単純な動作の詩的言い換えをせず、具体的な動作・表情・発言・手つきを直接書く。

**比喩を使わなくても同じ情報が伝わるなら、比喩を使わない。** 比喩は場面の核になるものだけに限り、原則として一場面に一つ以下とする。二段直喩（Xのような、Yのような）は、半分が同義の言い換えなら一つに削る。

**判定除外**（外形が5系統に似ていても違反として扱わない。外部監査など形だけを見る指摘を受けたときは、本項を根拠に採否を説明する）：

| 除外 | 例 | 理由 |
|---|---|---|
| 慣用として完全に定着した表現 | 目が覚める／目が笑っていない／手が覚えている／腹が減る／背中に声をかける／声が飛ぶ／噂が届く | 日本語の標準表現であり、直叙へ戻す先が存在しない |
| 和語の連体修飾による表情・様態 | いつもの顔で／泣き笑いの顔で／怖がりの顔のまま／当たり前の顔で／真ん中の顔 | 役割名詞の貼り付けではなく、表情そのものの描写 |
| 実在の人物を修飾語に取る所有 | 親父の声のまま／兄弟子の顔 | その人物の実際の声・顔を指す通常の所有関係 |
| 作中で実際に演じている役割 | 上客の口調のまま（人物が上客を演じている場面） | 貼り付けではなく、進行中の芝居を述べた事実 |
| 実体として設定された身体機能 | 獣人の耳が実際に聴き分ける（キャラシートに根拠があるもの） | 比喩ではなく設定どおりの知覚 |
| 作品世界の実物 | 迷宮の口・喉・肋骨（竜の骸そのものを迷宮とした設定の場合） | 実在する地形の名であり比喩ではない |
| 場面を更新する幻想・戦闘描写 | 霧がこちらに気づいて黙る層、と斥候が読む | 視点人物の知覚として情報を足しており、系統4に含めない |
| 標準的な構文 | 〜という顔ではない／〜という顔をする | 顔を役割名詞で置換していない |

除外に当たるかは形ではなく機能で決める。同じ「◯◯の顔」でも、役割名詞を貼って直叙を避けているなら違反、実際の表情や演技を述べているなら除外である。

**「側」の使い分け**：立場・役回りを指すときは自然（受け取る側、守られる側、教わる側）。非人格の名詞に付けると不自然になる（当たってほしくない側の予感、言葉の側へ）。顔・目など身体部位には付けない。

## 4. 笑い方・どもり・口癖の事故

### 4-1. 笑い方の単調化

| 禁止 | 理由 |
|---|---|
| 全キャラが「はっはっは！」 | 笑い方の使い回し |
| 「○○……はっはっは！」型を複数キャラが使用 | 同上 |
| 「うふふ」「ふふふ」を全女性キャラが使用 | 同上 |

対策：表記を固定するより、何を可笑しいと感じるか、誰の前で抑えるか、笑いが関係をどう変えるかを人物ごとに分ける。

### 4-2. どもりの誤り

「今度」のような漢字熟語のどもりで、**音読みの先頭文字を取る**：
- 正：「こ、今度」（こんど）
- 誤：「い、今度」（「今度」の読みの頭音と一致しない）

他の例：
- 「ご、ごめん」（OK）
- 「あ、ありがとう」（OK）
- 「ま、待って」（OK）
- 誤りやすい：「ひ、一年」（×：「一年」は「いちねん」と読むので「ひ」では始まらない）→ 「い、一年」（OK：「いちねん」の「い」）／「一日」は「いちにち」なら「い、一日」、「ついたち」なら「つ、一日」と、**読みの頭音に合わせる**

### 4-3. 関西弁・方言

書ける場合のみ使う。**中途半端な方言は事故になる**。書けないなら使わない。

## 4-4. 翻訳臭・直訳調（translationese／「ぬるい」型）

**シグナル**：英語の語感・コロケーション・構文・代名詞運用を日本語へ直訳的に移した結果、**文法的には正しいが日本語母語話者には不自然に響く**表現。翻訳・生成支援・参照資料の影響など原因は複数あり得るため、表現上の問題として扱う。

**優先順位（重要）**：コーパス研究では、翻訳調の「信頼できる指標」は**代名詞・所有格の過剰が筆頭**。無生物主語・カタカナ語・受動態は現代日本語にある程度定着しており文脈次第で許容される。**まず代名詞過剰を潰す**。

### ① 形容詞・形容動詞の語義外転用（コロケーション直訳）
「その形容詞は、その名詞に日本語慣用があるか」で判定。

| ダメ | 英語の元 | OK（対象固有の語へ）|
|---|---|---|
| 回線が**ぬるい** | weak/lukewarm | 回線が**細い／弱い／不安定**／電波が悪い |
| **強い**コーヒー | strong coffee | **濃い**コーヒー |
| **重い**雨 | heavy rain | **大雨／豪雨／激しい**雨 |
| **温かい**歓迎 | warm welcome | **心のこもった**もてなし／**手厚い**歓迎 |
| 声が**重い**（深刻の意）| heavy voice | 声が**低い／沈んでいる／かすれる** |
| **深い**〜の乱用 | deep ~ | 対象ごとに語を変える（強い懸念／気がかり）|

### ② 代名詞・所有格の過剰【最優先・最も確実な指標】
英語が文法上要求する代名詞・所有格を逐語移植する。日本語は文脈が立てば省くのが自然。

| ダメ | OK |
|---|---|
| **彼は彼の**恋人に会った | 恋人に会った |
| **彼は彼の**手を**彼の**ポケットに入れた | ポケットに手を入れた |
| **それは**理にかなっている | なるほど／筋が通る |
| **自分の**胸ポケットに触れた | 胸ポケットに触れた |

→ 地の文で「彼は／彼女は／それは／私は／自分の／彼の」が連続したら削れないか必ず点検。

### ③ 基本動詞 have / take / make の直訳
| ダメ | 英語の元 | OK |
|---|---|---|
| 問題を**持っている** | have a problem | 問題が**ある**／**抱えている** |
| 決断を**作る** | make a decision | 決断**する**／決定を**下す** |
| 視線を**取る**／一目**取る** | take a look | ちらっと**見る**／目を**やる** |

### ④ 構文・副詞の直訳臭（連発で立つ）
- 無生物主語＋使役（「薬は私を眠くさせる」→「薬のせいで眠くなる」）
- できる構文の冗長（「想像することができる」→「想像できる」）
- one of the（「最も〜のひとつ」→「屈指の〜」、数を消す）
- 自分の行為の受身化（「示されている」→「示す」）
- 談話標識の直訳（「文字通り／基本的に／実際に」は多く削れる）

**原則**：専門領域には現場の固有語がある（回線＝細い/太い/落ちる）。固有語を当てる。迷ったら直喩に逃げず**具体的事実・五感**で書く。
