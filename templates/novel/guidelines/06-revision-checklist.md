# 06. 推敲・校正チェックリスト

各章完成時に通す最終チェック。順序通り走査すること。生成原稿では**機械検出可能な事故**を先に除去できるため、目視より正規表現走査を優先する。

---

## A. 機械チェック（正規表現で自動走査）

### A-1. 記号・正書法
- [ ] マークダウン強調 `**` `*` が残っていない
- [ ] マークダウン見出し `## #` が残っていない
- [ ] 水平線 `---` `***` が残っていない
- [ ] コードブロック ` ``` ` が残っていない
- [ ] 箇条書き `* - 1.` が地の文に残っていない
- [ ] 三点リーダは「……」のみ（`…` `・・・` `...` `．．．` 混入なし）
- [ ] 三点リーダが偶数個（奇数個なし）
- [ ] ダッシュは「――」のみ（`ーー` `──` `--` `—` 混入なし）
- [ ] ダッシュが偶数個
- [ ] ダブルクォート `" "` が本文にない
- [ ] 半角スペースが日本語間に挟まっていない
- [ ] 閉じカギ前の句点なし（`。」` `！。` `？。` ゼロ）

### A-2. 他言語文字
- [ ] ハングル（`가-힣` 等）混入ゼロ
- [ ] ギリシャ文字（`Α-Ω` `α-ω`）混入ゼロ
- [ ] キリル文字（`А-Я` `а-я`）混入ゼロ
- [ ] 突発的な英単語混入ゼロ（多言語フィクションで意図的な場合を除く）
- [ ] アラビア数字が本文に出ていない（全角数字または漢数字）

### A-3. AIインターフェース痕跡
- [ ] 「分かりました」「承知しました」「了解しました」で始まる行なし
- [ ] 「以下、続きを書きます」型のプレフィックスなし
- [ ] 「ご要望があれば」「お知らせください」「いかがでしょうか」型のサフィックスなし
- [ ] 「進めていいですか」型の指示文なし

### A-4. 文字数・話数
- [ ] 「『○○』その○文字」が実文字数と整合（または書き換え済み）
- [ ] 「○話から」「○話で」型の話数地の文混入ゼロ
- [ ] 「○年間」が具体エピソードに紐付いている

---

## B. 語彙・表現チェック（手動＋検索）

### B-1. 語彙クラスタと役割
- [ ] 抽象動詞が、具体的な行為・対象・結果を隠していない
- [ ] 事務語・雰囲気語が狭い範囲に集まり、複数人物で同じ働きをしていない
- [ ] 反復句は、再登場によって意味・関係・状況が変わっている
- [ ] 名前は作品内の命名規則に合い、音・表記・呼称で人物を識別できる

### B-2. 動詞・形容詞
- [ ] 説明動詞が、必要な認識の明瞭さを保ちつつ、知覚・判断・行動の代用として反復していない
- [ ] 比喩・推量表現が対象を曖昧にする逃げになっていない
- [ ] 地の文の主語が人物になっている（「目が言った」「〜の顔で」「卓が笑った」「保留の棚」「噂が営業中」型の代理主語・物品管理化・擬人化＝圧縮癖5系統がない。`05-ai-guardrails §3-5`）。比喩は一場面一つ以下で、場面テスト（削って直叙に戻しても情報が減らないなら文飾。`§3-4`）を通るものだけ（`scripts/cliche_check.py` の警告が処理済み）
- [ ] 感情語と身体反応を使い分け、どちらも人物固有の選択へ接続している
- [ ] 同じ長さ・主語・構文・焦点の文末が続き、意図しない平坦さを生んでいない

### B-3. 反復
- [ ] 同じ決め台詞・相槌・言い回しの反復が、新しい意味を増やしている
- [ ] 同じフレーズ・言い回しがしつこく繰り返されていない
- [ ] 別キャラ・別視点で同じシーンが再描写されていない
- [ ] 話またぎの12字以上の逐語一致（`scripts/repeat_check.py`）が、変奏または `work/continuity/phrase-allowlist.txt` への理由つき登録で処理済み（`02-narrative §5-3`）

### B-4. 台詞の音と警句密度・語彙飽和（`02-narrative §4-8〜4-9・§2-6・§2-7`）
- [ ] 飽和注意語（`work/vocab-watchlist.tsv`）の話単位の出現数が `scripts/vocab_check.py` で上限内、または超過が除外欄で採否判断済み
- [ ] 職能比喩（計測・観測・査定など）が感情・関係の決め所へ転用されていない。救済・慰めの台詞は相手の語彙圏から取られている
- [ ] 切迫場面の指示台詞が音読テストを通る（能力パラメータの副詞直結・仕様記述の語順になっていない）
- [ ] 三連スローガン型の台詞が、確立済みの教え・口上の引用以外で使われていない
- [ ] 1場面の台詞の警句が目安1つに収まり、名前のない脇役が警句でオチを付けていない
- [ ] 各話に外し球（オチのない発話・言い淀み・凡庸な応答）が残っている
- [ ] 場面締めの一行警句（「〜らしい」「〜の形」型）が話内で1回までに収まっている

## C. 構造・整合性チェック

### C-1. キャラ一貫性（`character-sheet.md` と照合）
- [ ] 髪色・瞳色・身長が章を跨いで一貫
- [ ] 性別の代名詞「彼／彼女」がブレていない
- [ ] 一人称・二人称・語尾がキャラシート通り
- [ ] 敬語ライン（誰に敬語か）が一貫
- [ ] 地の文中の固有人名は、視点人物を含む全員が敬称・役職名なしの呼び捨て（中立呼称）になっている（台詞・引用・明示的な内心は除外）
- [ ] 禁則語を使っていない
- [ ] 身体的癖を出す場合、状況と人物に合い、記号的なノルマになっていない
- [ ] 退場済みキャラが復活していない

### C-2. 世界観一貫性（`world-bible/` と照合）
- [ ] 作品固有の階級・敬称・発言権ルールが守られている
- [ ] 規則から外れる呼称・口調・発言には、親密さ、反抗、無知、偽装など本文上の理由と結果がある
- [ ] 物品、作物、技術、価格が、作品の参照時代・地域・交易・魔法設定と整合する
- [ ] ドレス・服飾の物理整合OK
- [ ] 通貨・度量衡が一貫

### C-3. 時系列・場所（`world-bible/core/08-timeline.md` と照合）
- [ ] 当該話の作中日付が 08-timeline §3 の前話の行と整合（経過日数・季節）
- [ ] 朝→夜の時間飛躍が明示されている
- [ ] 同時刻に複数の場所にいる事故なし（08-timeline §3 の「同期」列で確認）
- [ ] 季節・天候が前後と整合
- [ ] 年齢と経歴が整合（18歳が「15年勤めた」等の事故なし。作中暦は 08-timeline §1 が正本）
- [ ] 親族の生死・所在が整合（5年前死んだ先妻の3歳児等の事故なし）
- [ ] 章完成後、08-timeline §3 に当該話の行を追記した

### C-4. 関係性
- [ ] 婚約者・主従・親族関係が`character-sheet.md`と整合
- [ ] 経済関係（借金・肩代わり等）が章を跨いで一貫

## D. 描写・五感チェック

### D-1. 感覚の機能
- [ ] 感覚描写が、危険、欲求、記憶、判断、階級、生活のいずれかに効いている
- [ ] 食事や物品の具体性が、固有名詞の飾りではなく人物と世界の条件を渡している
- [ ] 五感を同数配置せず、視点人物が拾うものと見落とすものに偏りがある

### D-2. 身体性
- [ ] 身体反応を使う場合、人物の体質・抑制・状況に固有で、行動や判断へつながっている
- [ ] 感情語、身体、行動、台詞のうち場面に必要な手段を選び、毎回同じ変換をしていない

---

## E. 構造・進捗チェック

### E-1. 章単位
- [ ] 作品が採用した構造上の機能、またはscene-cardの局所目標が達成された
- [ ] 話末で今回の状態変化を受け取れ、次に残る圧力または余韻が分かる
- [ ] 話内で物語が一歩進んだ（情報開示／関係変化／位置・期限・危険／決断／喪失獲得などが以後の選択を変える）
- [ ] 作品の目安字数から外れる場合、分割・統合より現在の切れ目が有効な理由がある

### E-2. 視点
- [ ] 各場面内で視点キャラが一人に固定され、視点変更は場面境界だけで `pov-plan.md` の割当どおりに行われている
- [ ] 視点キャラ以外の内面が地の文で描かれていない（推察形ならOK）
- [ ] カメラ位置が1段落内で動いていない

## F. 出力前最終確認

- [ ] 章タイトルにマークダウン記法・派閥揺れ記号・半角スペース混入なし
- [ ] あらすじが定型文だけで終わらず、主人公の立場・変化・対立・期待する読み味を必要な範囲で伝える
- [ ] ルビ記法が投稿先（カクヨム／なろう）に合致
- [ ] 段落冒頭が全角1字下げ
- [ ] 場面区切りの空行ルールが作品全体で一貫

## G. 読後感ルーブリック（観点15）

ai-novel-detector の観点15（読後感の希薄さ）に対応。章を最後まで読んだ直後に、各軸の根拠箇所を短く記録する。点数は比較用の補助であり、閾値だけで改稿を決めない。

### G-1. 認知・密度・余韻（5段階評価）

| 項目 | 1（NG）| 5（合格） |
|---|---|---|
| 認知の手触り | 情報要約だけで、誰が何をどう受け取ったか見えない | 視点人物の偏り、選択、見落としが具体的に残る |
| 密度 | 同じ情報や感情を言い換えて反復する | 各段落が新しい具体、判断、含意のいずれかを運ぶ |
| 状態変化 | 出来事が並ぶだけで前後差がない | 話末で判断、関係、危険、資源、意味のいずれかが変わる |
| 文体固有性 | 人物や場面を替えても語彙・比喩・文調が同じ | 視点人物と場面の圧力に応じた選択がある |
| 構造 | 説明文＋台本のような構造（地の文が短文ポエム）| 説明・描写・台詞が呼吸している |
| 食品サンプル感 | 「小説風の文字列」で物語が起きていない | 物語が起きている |
| 携帯小説感 | 一文一段落・モノローグ過多 | 段落が文章として連動している |
| 継続理由 | 整っているが、今回の返済も次の圧力も見えない | 約束への返済、問い、余韻など作品に合う継続理由がある |

### G-2. 機械的検出が困難な質的項目

機械検出（A〜B）を全部通っても**読後感が悪い**ことがある。その場合は以下を疑う：

- [ ] 感情の強弱や表出方法が、人物を替えても同じパターンになっていない
- [ ] 食事、移動、会議などの反復場面が、前回と同じ情報だけを運んでいない
- [ ] 身体的距離や接触の有無が、関係性と場面の圧力に合っている
- [ ] 話末の効果が連続して同じになり、予測可能な型になっていない
- [ ] 視点人物の選択または選ばないことが、結果と責任へ接続している
- [ ] 副筋の停止が意図的な保留か、単なる忘却かをplotの次回条件で説明できる

### G-3. 改稿の優先順位

G-1・G-2 で問題が出た場合、以下の順で直す：

1. **状態変化と継続理由**（G-1）→ 場面の選択・結果・約束への返済を先に直す
2. **認知の手触りと文体固有性**（G-1）→ 視点人物固有の着眼、判断、見落としを必要な箇所へ戻す（`02-narrative-craft §1`）
3. **副筋停滞**（G-2）→ 再開、主筋への合流、意図的保留、終了のどれかをplotへ明記し、必要な場合だけ本文を直す
4. **話末の単調化**（G-2）→ その話の状態変化から最も自然な余韻・圧力へ戻す（`04-structure §2-3`）

## 推奨ワークフロー

1. 章本文を生成
2. **A 機械チェック** をスクリプト実行（`scripts/check.sh`、話またぎ反復は `scripts/repeat_check.py`、語彙飽和は `scripts/vocab_check.py`）
3. 検出違反を全修正
4. **B 語彙チェック** を grep で実行
5. **C 整合性チェック** をキャラシート・世界観Bible と照合
6. **D 描写チェック** を目視
7. **E 構造チェック** を目視
8. **F 最終確認** で投稿前ゲート
9. **G 読後感ルーブリック** で根拠箇所を記録し、必要な箇所だけ改稿

A〜Gを通過した章のみを公開する。Gの数値だけで合否を決めず、読者効果を損なう根拠箇所がある場合だけ改稿して再度ループする。
